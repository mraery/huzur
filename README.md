## 🌿 Öne Çıkan Özellikler

1. **3D Kart Destesi & Sağa/Sola Kaydırma (Swipe Physics)**:
   - Parmağınızla veya farenizle kartı sağa savurduğunuzda olumlama kalbinize (**Favoriler**) kaydedilir.
   - Sola savurduğunuzda sıradaki olumlamaya geçilir.
   - Her olumlama için özenle hazırlanmış aurora renk gradyanları ve tefekkür notları.

2. **Gerçek Zamanlı Web Audio API Ortam Sesleri**:
   - 🏕️ **Gece Kampı**: Çıtırdayan kamp ateşi ve sıcak gece esintisi.
   - 🦗 **Gece Ormanı**: Huzurlu yaz gecesi cırcır böcekleri.
   - 🌧️ **Yağmurlu Pencere**: Akan orman deresi ve su damlaları.
   - 🎹 **Huzur Piyanosu**: 432Hz meditatif akorlar ve geniş yankı.
   - 🌊 **Sakin Okyanus**: Gel-git dip dalgası.
   - 🔔 **Zen Tapınağı**: Tibet çanağı harmonikleri.

3. **📸 Yüksek Çözünürlüklü Kart İndirme (PNG)**:
   - Olumlamayı tek tıkla 1080x1350 formatında şık bir Instagram hikayesi veya durum görseli olarak kaydedin.

4. **⏱️ Dinginlik & Meditasyon Zamanlayıcısı**:
   - 3, 5, 10 ve 15 dakikalık dinginlik seansı seçimi. Seans bittiğinde çan sesiyle uyanış.

5. **📱 Ana Ekran Widget Simülatörü**:
   - iOS ve Android ana ekranlarında olumlamanın nasıl görüneceğini deneyimleyin ve PWA desteğiyle telefonunuzun ana sayfasına ekleyin.

## 💻 Geliştirici & Yerel Çalıştırma

### Web Olarak Çalıştırma:
```bash
cd web
python -m http.server 8080
```
Tarayıcınızda `http://localhost:8080` adresine gidin.

### Flutter Android Olarak Çalıştırma:
```bash
flutter pub get
flutter run
```
